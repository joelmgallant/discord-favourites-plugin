# Discord Favourites Plugin - Quick Install

## Windows

1. Extract this zip
2. Double-click `install-windows.bat`
3. Restart Discord
4. Go to Vencord Settings > Plugins > Enable "FavouritesPanel"

## macOS

1. Extract this zip
2. Open Terminal, `cd` into the extracted folder
3. Run `./install-mac.sh`
4. Restart Discord
5. Go to Vencord Settings > Plugins > Enable "FavouritesPanel"

## Linux

1. Extract this zip
2. Open terminal, `cd` into the extracted folder
3. Run `./install-linux.sh`
4. Restart Discord
5. Go to Vencord Settings > Plugins > Enable "FavouritesPanel"

## What This Does

This installs a custom build of Vencord (Discord client mod) that includes the Favourites Panel plugin. The plugin adds a star icon to your server list that opens a panel showing all your favourite channels across servers.

## Uninstall

To remove, run the installer again with `--uninstall` or reinstall standard Vencord from https://vencord.dev.
